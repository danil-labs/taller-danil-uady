# Coordinación editorial

@coordinador crea aquí el encargo, esquema, registro de afirmaciones e informe de
revisión al comenzar un documento. @bibliotecario registra fuentes y @ilustrador
la procedencia editorial de figuras. No hay todavía un encargo ejecutado por la
flota nueva. Cada archivo tiene un solo escritor; @revisor entrega su dictamen
en la respuesta y no modifica esta carpeta.
