# Taller Danil UADY

Material para el taller de ingeniería con agentes de IA en Terminus.

## Presentación

Abre `presentacion/entre-el-orden-y-el-caos.html` en tu navegador. Usa las flechas para avanzar y retroceder; las animaciones se reproducen a mayor velocidad. Las diapositivas incluyen simulaciones interactivas. También está disponible una versión estática en PDF en la misma carpeta.

La presentación proviene del taller «Entre el orden y el caos». Los créditos de sus imágenes están en `presentacion/CREDITOS.md`.

## Agentes

La carpeta `agentes/` queda preparada para incorporar los agentes del taller.
